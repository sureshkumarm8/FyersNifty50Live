================================================================================
                    ENVIRONMENT VARIABLES SETUP GUIDE
================================================================================

PROBLEM:
--------
Frontend showing 401 Unauthorized error when calling /api/paytm/quotes
This happens when credentials.paytmAccessToken is undefined.

ROOT CAUSE:
-----------
Environment variables not properly set in Vercel production deployment.

SOLUTION - VERCEL ENVIRONMENT VARIABLES:
-----------------------------------------

Go to: https://vercel.com/your-project/settings/environment-variables

Add these REQUIRED variables:
┌──────────────────────────────────────────────────────────────┐
│ Variable Name              │ Value                           │
├──────────────────────────────────────────────────────────────┤
│ PAYTM_ACCESS_TOKEN         │ Your PayTM JWT token            │
│ UPSTASH_REDIS_REST_URL     │ https://xxx.upstash.io          │
│ UPSTASH_REDIS_REST_TOKEN   │ Your Upstash token              │
│ KV_REST_API_URL            │ (same as UPSTASH_REDIS_REST_URL)│
│ KV_REST_API_TOKEN          │ (same as UPSTASH_REDIS_REST_TOKEN)│
└──────────────────────────────────────────────────────────────┘

Optional but recommended:
┌──────────────────────────────────────────────────────────────┐
│ ENCRYPTION_KEY             │ Random 32-char string           │
│ CONFIG_SECRET              │ Random secret for /api/get-config│
│ CRON_SECRET                │ Secret for cron-job.org auth    │
│ BYPASS_MARKET_HOURS        │ true (for testing only)         │
│ GOOGLE_API_KEY             │ For AI features                 │
│ GROQ_API_KEY               │ For AI features                 │
└──────────────────────────────────────────────────────────────┘

IMPORTANT: Set for ALL environments (Production, Preview, Development)

HOW THE SYSTEM WORKS:
---------------------

1. FRONTEND APP LOADS:
   ├─ Calls /api/get-config
   ├─ Backend reads process.env.PAYTM_ACCESS_TOKEN
   ├─ Encrypts and sends to frontend
   ├─ Frontend decrypts and stores in credentials.paytmAccessToken
   └─ Frontend can now call PayTM APIs via proxy

2. FRONTEND APP RUNNING (User active):
   ├─ Sends "frontend_active" heartbeat to Redis
   ├─ Fetches live data from PayTM via /api/paytm/quotes
   ├─ Saves data to Redis via /api/save-redis-data
   └─ Cron-job SKIPS fetch (sees heartbeat)

3. FRONTEND APP CLOSED (Background mode):
   ├─ No heartbeat in Redis
   ├─ Cron-job.org calls /api/cron-fetch every minute
   ├─ Fetches live data using process.env.PAYTM_ACCESS_TOKEN
   ├─ Saves to Redis
   └─ Ready for next frontend session

VERIFICATION STEPS:
-------------------

1. Check Vercel environment variables:
   vercel env ls

2. Test /api/get-config endpoint:
   curl https://your-app.vercel.app/api/get-config
   # Should return: {"success":true,"encrypted":{...}}

3. Check browser console on app load:
   ✅ Loaded encrypted config from backend
   ✅ [PayTM] Fetching LIVE data directly from API...

4. If you see:
   ℹ️ Backend config not available, using localStorage
   → Environment variables NOT set in Vercel

TESTING LOCALLY:
----------------

Create .env.local file:
```
PAYTM_ACCESS_TOKEN=your_token_here
UPSTASH_REDIS_REST_URL=https://xxx.upstash.io
UPSTASH_REDIS_REST_TOKEN=your_token_here
KV_REST_API_URL=https://xxx.upstash.io
KV_REST_API_TOKEN=your_token_here
```

Run:
npm run dev

DEPLOYMENT CHECKLIST:
---------------------
□ Set PAYTM_ACCESS_TOKEN in Vercel
□ Set Redis credentials (UPSTASH_*)
□ Redeploy: vercel --prod
□ Open app and check console logs
□ Verify no 401 errors
□ Check Redis has data: curl /api/get-redis-data

TROUBLESHOOTING:
----------------

Error: 401 Unauthorized on /api/paytm/quotes
→ PAYTM_ACCESS_TOKEN not set in Vercel OR config not loading

Error: Cannot read properties of undefined (reading 'toString')
→ credentials.paytmAccessToken is undefined
→ Check console for "Loaded encrypted config" message

Error: PayTM API Error (401)
→ PAYTM_ACCESS_TOKEN is invalid or expired
→ Generate new token from PayTM Money Developer Portal

CRITICAL FILES:
---------------
1. api/get-config.js        - Encrypts and sends env vars to frontend
2. utils/configLoader.ts    - Decrypts config on frontend
3. App.tsx (line 120-131)   - Loads config on mount
4. api/paytm/quotes.js      - Proxy for PayTM API
5. api/cron-fetch.js        - Background data fetch

SECURITY NOTES:
---------------
✅ Tokens encrypted in transit (AES-256-CBC)
✅ Frontend never stores plain tokens
✅ Backend validates requests
✅ Cron endpoints protected with CRON_SECRET
⚠️  Do NOT commit .env.local to git
⚠️  Rotate tokens if exposed
