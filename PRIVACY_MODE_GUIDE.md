# 🔒 Privacy Mode Guide

## Quick Start

**Privacy Mode** helps you hide the Markets dashboard from onlookers in the office. Perfect for when colleagues walk behind your desk.

---

## Features

### 1. **Emergency Hide** - Instant Activation
- **Keyboard Shortcut**: `Cmd+Shift+V` (Mac) or `Ctrl+Shift+V` (Windows/Linux)
- **Button**: Look for the Eye icon in the header (turns red when active)
- **Instant**: Press once to hide everything immediately
- **Reversible**: Press again to resume normal view

### 2. **Decoy Mode** - Plausible Deniability
When Privacy Mode is active, you can toggle a generic "work in progress" dashboard:
- Shows time, date, and generic placeholders
- Looks like a productivity/project management tool
- Perfect for when someone walks by and you need to show an innocent screen
- Toggle with the "Show Decoy Dashboard" button

---

## How to Use

### Activate Privacy Mode
1. **Quick method**: Press `Cmd+Shift+V` (or `Ctrl+Shift+V` on Windows)
2. **Button method**: Click the Eye icon in the top-right header
   - Red eye icon = Privacy Mode ON
   - Regular eye icon = Privacy Mode OFF

### Toggle Decoy Dashboard
When Privacy Mode is active:
1. Click "Show Decoy Dashboard" button
2. A generic work dashboard appears
3. Click again to toggle it off
4. Still completely hidden from view

### Resume Normal View
1. Press `Cmd+Shift+V` again, OR
2. Click the "Resume" button in the Privacy Mode screen
3. Returns to your previous view (Summary, Stocks, Options, etc.)

## Troubleshooting

**Q: Keyboard shortcut not working?**
- A: Make sure the app window has focus (click somewhere in the app first)
- Try `Ctrl+Shift+V` if on Windows/Linux instead of `Cmd+Shift+V`

**Q: Can I customize the decoy dashboard?**
- A: Currently it shows generic placeholders. Contact support for custom layouts.

**Q: Will my settings be saved?**
- A: Yes! All app settings and preferences persist. Privacy Mode is stateless.

**Q: Can I see market data while in Privacy Mode?**
- A: No, that's the whole point! All market content is hidden. For maximum privacy, use Decoy Mode too.

## FAQ

**Q: Can data be lost when using Privacy Mode?**
- A: Absolutely not. All data is preserved. It's just hidden visually.

**Q: Is this feature available on mobile?**
- A: Currently optimized for desktop. Mobile support coming soon.

**Q: Can I use Privacy Mode without Decoy Mode?**
- A: Yes! Privacy Mode alone just shows a blank screen. Decoy Mode is optional.

**Q: What happens to real-time updates when Privacy Mode is on?**
- A: They continue silently. When you resume, data is fresh and current.
