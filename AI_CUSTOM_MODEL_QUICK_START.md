# 🚀 AI Custom Model - Quick Start Guide

## ⚡ 5-Minute Setup

### **Step 1: Enable AI (30 seconds)**
```
1. Open your app
2. Click "Settings" ⚙️
3. Toggle "AI Enabled" to ON
4. Select AI Provider (Gemini recommended)
5. Ensure API key is present
6. Click Save
```

### **Step 2: Navigate to Patterns (10 seconds)**
```
1. Click "Patterns" 🔮 button in top navigation
2. See AI Prediction panel at top (purple gradient)
3. Wait for live market data
```

### **Step 3: Get Your First Prediction (30 seconds)**
```
1. Click "Get AI Prediction" button
2. Wait ~5-10 seconds for AI analysis
3. See prediction with:
   - Direction (📈 BULLISH / 📉 BEARISH / ➡️ NEUTRAL)
   - Confidence (0-100%)
   - Expected Move (in points)
   - Risk Level (🟢 LOW / 🟡 MEDIUM / 🔴 HIGH)
   - AI Reasoning (why this prediction)
```

---

## 📊 Understanding Your AI Predictions

### **Direction**
- **📈 BULLISH**: Market likely to go UP
- **📉 BEARISH**: Market likely to go DOWN  
- **➡️ NEUTRAL**: Market likely to stay SIDEWAYS

### **Confidence Level**
- **80-100%**: 🟢 Very High - Strong signal
- **60-79%**: 🟡 High - Good signal
- **40-59%**: 🟠 Medium - Moderate signal
- **0-39%**: 🔴 Low - Weak signal

### **Expected Move**
- How many points Nifty is expected to move
- Example: +30 pts = Nifty may rise 30 points
- Example: -45 pts = Nifty may fall 45 points

### **Risk Level**
- **🟢 LOW**: Safe market conditions
- **🟡 MEDIUM**: Normal risk
- **🔴 HIGH**: Volatile, risky conditions

## 🎯 Using AI Features

### **1. Get Pattern Explanations**
```
1. In Pattern Dashboard, scroll to "Pattern Library"
2. Click on any pattern
3. Click "Get AI Explanation" button
4. Read AI's analysis of that pattern
```

### **2. Auto-Refresh Predictions**
```
- AI predictions auto-refresh every 2 minutes
- Or click "Refresh Prediction" button anytime
- Fresh data = better predictions
```

### **3. Monitor Learning Statistics**
```
Top of AI panel shows:
- Total Patterns: How many patterns AI has learned
- Accuracy: How often AI was correct (%)
- Recent: Accuracy of last 20 predictions (%)
- Confidence: Average confidence level (%)
```

### **High Confidence Trades** (Recommended)
```
✅ Confidence > 70%
✅ Risk Level: LOW or MEDIUM
```

```
→ Wait for confirmation or use smaller position
```

### **Low Confidence** (Avoid)
```
❌ Confidence < 50%
❌ Risk Level: HIGH
→ Stay out, wait for better setup

```

## 🔧 Troubleshooting

### **"AI is not enabled in settings"**
```
→ Go to Settings
→ Enable "AI Enabled" toggle
→ Add API key if needed
→ Return to Patterns view
```

### **"Failed to get prediction"**
```
→ Check internet connection
→ Verify API key is valid
→ Check API quota (daily limits)
→ Try different provider (Groq has high limits)
```

### **"Waiting for live market data"**
```
→ Ensure market is open (9:15 AM - 3:30 PM)
→ Check WebSocket connection
→ Refresh page
→ Wait for first data snapshot
```

### **Predictions seem inaccurate**
```
→ Give it 1-2 weeks to learn
→ Check if accuracy is improving in stats
→ More historical data = better predictions
→ Market conditions change (AI adapts)
```
